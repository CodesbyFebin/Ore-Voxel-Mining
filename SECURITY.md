# Security and responsible testing

EdgeORE is an experimental playable voxel game with a read-only ORE information terminal. Do not use it to transmit private keys or expect real ORE payouts. Financial transaction signing and Deploy/Checkpoint/Claim must remain disabled until independently qualified.

Report vulnerabilities privately using GitHub's security advisory reporting if enabled, or contact the project owner before public disclosure. Avoid posting credentials, wallet secrets, or exploit details in public issues. Upstream libraries retain their own licenses and security policies.
