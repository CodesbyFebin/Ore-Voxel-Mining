# OREBunker focused launcher

Modes: ORE Quarry, SOL Caverns, Mining Rig Network and 60-second ORE Hunt. No unrelated creative or generic library modes.

Start: `python3 orebunker-launcher/launcher.py` after installing Luanti and Python Tkinter.

Native mod supports mining-themed scoring, in-game virtual rig inspection/upgrades and safe wallet separation. Previous `orebunker_core` remains intact.

The on-chain wallet companion is scoped separately. Real cryptocurrency mining cannot be triggered by simply breaking in-game blocks: authoritative protocol SDK verification, real wallet consent, and a secure runtime are required.

Qualification: source-level patch only. Native Luanti runtime and game UI are not verified here.
